# iPhone Use 原生 2.0 产品化改造

## 目标与范围

将桌面默认入口升级为原生 AppKit 三栏设备工作台，沿用确认的 2.0 效果图风格。左侧负责设备发现与选择，中间展示画面，右侧提供当前设备的状态、控制和接入说明。不引入 WebView、Electron 或第二套采集/输入服务。

原始设计素材、真实设备截图、完整诊断日志和本机事务归档仅保留本地，不随公开 PR 提交。

## 实现步骤与具体目标

| 模块 | 已实现目标 | 验证方式 |
| --- | --- | --- |
| 状态与生命周期 | 完整设备 ID 路由；同名隔离；断线保留；quiet 常驻；独立窗口及旧 UI 回退 | 状态/生命周期定向测试 |
| 工作台与样式 | 原生三栏；浅色/深色；中英文；空状态；卡片、Inspector、连接引导 | 原生离线导出与局部界面核对 |
| 多设备浏览 | 平铺/聚焦；每页最多 3 台，按宽度降为 1/2 台；左右翻页；空白与外框可选中 | 状态/命中区域定向测试 |
| 设备模型与按钮 | iPhone SE、iPhone 12 等外框适配；按钮瞬时反馈；卡片“扩大”直接打开对应独立窗口 | 几何/按钮测试及局部真机核对 |
| 输入与文本 | 复用 PhoneControlView；本地编辑菜单；按设备保留草稿；忙碌/失败反馈；取消不重放输入 | 文本/焦点定向测试及部分真机交互 |
| 弹窗与接入 | 连接指导放在 Inspector；AI/MCP、API、连接指南采用工作台级原生弹窗，不覆盖手机内容 | 弹窗定向测试与原生界面核对 |
| 后端偏好 | 按完整 ID 保存用户明确选择；无记录时 iOS 26+ 默认 USB Touch，旧版/未知版本默认蓝牙；准备失败不自动回退 | 默认值、持久化和隔离测试 |
| 画面身份与 USB 恢复 | 拓扑变化先关闭画面读取，确认身份后恢复；USB 准备等待身份确认，忽略过期 capture 结果；保留底层错误并提供显式重试 | 身份/USB 定向测试、只读状态核对 |

采集、BLE HID、USB Touch、HTTP/MCP 继续共享既有服务边界；不自动重放失败动作、不按名称/前缀重新绑定设备。界面截图导出也受当前设备身份门控。

## 运行与回退

```sh
swift run iphone-use
IPHONE_USE_LEGACY_UI=1 swift run iphone-use
```

离线预览在 DDI、蓝牙、采集和 HTTP 服务启动前退出：

```sh
swift run iphone-use --workbench-preview /tmp/iphone-use-workbench.png
# 可选：--empty --en --dark --focus --narrow
# 多设备分页示例：--devices 6 --page 2
# 工作台弹窗：--dialog mcp（也可选 api、guide）
# --assets DIR 加载显式示例图片，不进行真机采集。
```

## 验收与边界

软件验证与真机验收分开记录，见 [ACCEPTANCE.md](ACCEPTANCE.md)。离线 fixture、原生 PNG、USB ready 状态不等同于全部真机动作已验收。

本 PR 不包含可视化自动化编排、调度引擎、录屏、远程控制、收费体系或自动 DDI 安装。物理断连后画面稳定性重复回归、真实按下状态下的拖动取消等仍需补验，不能作为发布完成项。
