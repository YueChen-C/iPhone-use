# 指针校准基础数据

此目录保存去除手机身份信息的参考测量数据，用于比较加速曲线和选择待验证的初始参数。它与 `Application Support/iPhoneUse/pointer-calibration/` 中绑定 USB、蓝牙身份的单机配置分别保存。

主程序不会直接读取或打包此目录。`scripts/calibrate-pointer.py --auto` 会优先验证已有映射；失败后，将此目录中相同物理分辨率的数据作为候选，在目标手机实测验证。通过后保存为绑定当前手机身份的配置；失败则恢复原文件与运行时输入，再测量目标手机自己的曲线。不同分辨率不会自动缩放套用。也可以通过 `--baseline <JSON 路径>` 指定某台手机的运行时配置作为候选；来源手机的身份不会迁移。

上述身份核验只证明当次画面与实体设备的对应关系。后续重启后，主程序和独立的 AVFoundation 视频捕获都出现了设备 UID 与实际像素来源交叉的情况，已由独立 `screenshotr` 截图对照确认。因此，不能把相同的捕获 UID 当作重连后画面来源始终不变的保证；重连后应重新核对实际画面来源，再确认蓝牙关联及模板归属。该后续异常不改变上表在身份已核实阶段获得的 32 档实测结果。

多设备时，主程序现在可借助本机可选的 `idevicescreenshot`，独立获取各 USB 手机的截图，与 AVFoundation 画面比较；只有两轮得到一致、唯一且完整的映射才标记为 `verified`。验证只在捕获设备拓扑变化或显式 `/match` 重试时进行，轮询状态不会重复截图。`pending`、`failed` 时阻断匹配和输入，不会通过交换或重测曲线修复画面身份；缺少可用截图工具时为 `unavailable`，保留未验证的名义映射，后续蓝牙关联仍须运动证明，不能将此回退视为独立 USB 身份验证。状态与 `physicalID`、`sourceID`、`identityVerified` 可在 `/status` 或 `/devices` 的 `capture` 对象检查。

两台手机同为 iOS 15、分辨率相同，32 档实际位移仍不一致。这些观测无法单独区分型号、系统小版本与跟踪设置各自的影响，目标手机仍须实测验证候选曲线。

## 数据含义

- `schemaVersion`：基础数据格式版本，区别于运行时单机配置格式。
- `reference`：测量时的型号、系统、画面尺寸及已知设置；`screenWidth`、`screenHeight` 的单位是物理像素。
- `distances[n]`：一次幅度为 `n` 的单轴相对 HID 报告，平均移动的物理像素数。数组从 `0` 开始。
- `vectorModel`：经这台参考手机的测量验证的对角位移模型，仍需在目标手机验证后启用。
- `validation`：此文件的复用边界。`requiresLiveVerification` 为 `true` 时，候选参数必须经过实际落点检查。

## 分辨率与复用

| 变化 | 处理方式 |
| --- | --- |
| 同一台手机，只缩小 Mac 预览或 API 截图 | 将截图坐标换算回手机比例坐标，继续使用原物理像素曲线。 |
| 手机实际捕获尺寸改变 | 原运行时配置的尺寸检查会拒绝坐标操作；为新尺寸选择或测量参数，不能只改配置中的宽高。 |
| 不同手机，即使分辨率相同 | 型号、系统和跟踪设置仍可能影响曲线，先作为候选参数验证。 |
| 系统、跟踪速度、显示缩放或发送节奏改变 | 检查原曲线是否仍然匹配，失效后重新测量。 |

以 SE 的 `distances[16] ≈ 27.66` 为例，该数值表示约 27.66 个物理像素，不表示屏幕宽度的固定比例。因此不能直接按新旧屏幕宽度之比缩放全部 `distances`。

若后续对照实验确认两台设备在相同设置下有一致的逻辑点位移曲线，可以用下式生成候选值，再验证实际落点：

```text
logicalDistance[n] = reference.distances[n] / reference.devicePixelRatio
candidateDistance[n] = logicalDistance[n] × target.devicePixelRatio
```

这只是有条件的候选换算；当前数据尚未验证这一假设，不自动按 DPR 或分辨率比例迁移。手机配置通过验证后，应继续按 USB 身份在应用数据目录长期保存。

多设备中仅部分手机支持独立截图时，主程序会继续验证可截图的手机；只剩一台明确不支持截图的手机和一条可识别视频流时，可在两轮一致后按排除法补齐。无法完整确认时使用 `partiallyVerified`，仅开放已验证手机的输入，其他手机不会拖累它们。截图失败或图像矛盾不能使用排除法，且这些处理不会改写已有校准曲线。
